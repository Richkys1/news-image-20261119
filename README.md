The front page of Thursday 19 November 2026 in one image: the first-ever
Trump–Xi–Putin trilateral summit and its "peace declaration" lead, with the
ICJ's Myanmar genocide ruling, the third strike on the Kerch Bridge, the
missile over Riyadh's PIF Tower, the record Anthropic IPO, the record Van
Gogh sale and COP31 in Antalya. Drawn deterministically with Pillow and
DejaVu fonts by `generate.py`; `main.py` writes it to `entry.png`.

## Run it

```sh
python3 generate.py entry.png
```

The same command run twice produces byte-identical output, and the image
is a 1024x1024 PNG under 1 MiB.
